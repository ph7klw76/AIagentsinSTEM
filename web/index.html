    THE EXECUTABLE LABORATORY

    Make the claim
    earn your confidence.

    Calculate an axial-bar reference solution, test an amplifier’s gain and bandwidth separately, and explore how a low mean can hide intermittent occupancy.

    These small teaching models expose assumptions. The water-count example is synthetic; it is not a new molecular dynamics result.

    Launch the Python lab ↗Download the notebook

    First launch

    1. Wait for the notebook and kernel to load. If asked, choose Python (Pyodide). Wait until the kernel status says Idle before running cells.
    2. Use Run → Run All Cells. Check the numerical comparisons and the final plots.
    3. Change a parameter, rerun and explain which conclusion changes.
    4. Download your notebook to keep your work.

    The first launch downloads the browser runtime and packages. Local browser storage can be cleared; download your work. Desktop Python instructions are in the repository.

    TRANSFER TASK / THE UNFAMILIAR CASE

    A new model. The same standard.

    An AI proposes an amplifier with gain 8 and a 200 kHz cutoff for a task requiring gain ≥10 and cutoff ≥150 kHz. Use the notebook to evaluate it. Then explain why passing one requirement cannot compensate for failing another.

    Review guide

    The proposed model passes the bandwidth threshold and fails the gain threshold. State the model’s small-signal, single-pole assumptions. List at least one hardware effect this simple model cannot verify, and identify the evidence you would request before fabrication.

    Evidence checklist

    For a workflow in your own field, state the question and units; retain the exact inputs and software versions; separate execution status from scientific acceptance; perform an independent check; and describe the limits of the conclusion.
